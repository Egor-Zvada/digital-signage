# Клиент-экран: любой браузер

На клиентское устройство ничего из проекта устанавливать не требуется. Подходит
Raspberry Pi 5, мини-ПК, обычный компьютер, телевизор или медиаплеер, если на нём
есть современный Chromium/Chrome/Edge с поддержкой Service Worker и Cache Storage.

## Подключение

1. В панели сервера откройте **Экраны**.
2. Создайте экран и один раз скопируйте его постоянную секретную ссылку.
3. Откройте эту ссылку в браузере.
4. Включите полноэкранный режим или настройте автоматический запуск браузера в
   режиме kiosk с этой ссылкой.

Пример для Chromium:

```bash
chromium --kiosk --no-first-run --disable-session-crashed-bubble \
  --autoplay-policy=no-user-gesture-required \
  'https://signage.vve.local/display/ID/TOKEN/'
```

На клиенте должен быть доверен CA, выпустивший сертификат `signage.vve.local`.
Предпочтительный вариант — существующий корпоративный Microsoft CA. Встроенный
Signage CA является только начальным вариантом для среды без собственной PKI; его
публичный сертификат доступен по адресу
`http://signage.vve.local/signage-ca.crt`. Получать доверенный корневой сертификат
только по незащищённому HTTP без заранее проверенного отпечатка нельзя.

## Автономная работа

Страница сама сохраняет оболочку player, текущий manifest, медиа текущей и
предыдущей опубликованных ревизий. Новая ревизия включается только после полной
последовательной загрузки **всех** её фото, видео и снимков сайтов и проверки их
SHA-256. Это не потоковая схема YouTube. При кратком отключении сети или сервера
показ продолжается из кеша. Живые внешние сайты требуют сети; для гарантированного
показа используйте режим **Снимок сайта**.

Для надёжности не используйте приватный режим браузера и не очищайте данные сайта
`signage.vve.local`. Для каждого физического экрана рекомендуется отдельный
профиль браузера.

Подробности, ограничения больших видео и настройка Microsoft CA описаны в
[полном русском руководстве](user-guide-ru.md).
