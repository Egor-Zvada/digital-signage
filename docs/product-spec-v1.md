# Спецификация v1

## Развёртывание

- Proxmox VE 9.2.3.
- Один непривилегированный LXC Debian 13.
- Без Docker и Docker Compose.
- Все сервисы запускаются отдельными unit-файлами systemd.
- Данные и медиа находятся на виртуальном диске LXC.
- Адрес сервера: `signage.vve.local` (`192.168.110.222`).
- Часовой пояс: `Asia/Sakhalin`.

## Контент

Поддерживаются фото, видео, живые URL, серверные снимки URL и встроенные сцены.
Контент хранится в библиотеке и может повторно использоваться в нескольких
плейлистах. Переименование меняет только метаданные. Удаление сначала мягкое.

Элемент плейлиста содержит порядок, активность, длительность, расписание,
громкость, способ масштабирования и настройку фирменного оверлея. После конца
очереди воспроизведение начинается заново.

## Расписание

- начало и конец периода;
- дни недели;
- ежедневный интервал времени;
- часовой пояс канала;
- необязательные границы периода;
- вычисление на клиенте по синхронизированному серверному времени.

## Каналы и экраны

Экран имеет постоянную секретную ссылку. Канал можно переназначить без изменения
ссылки. Канал публикуется неизменяемыми ревизиями. Клиент активирует новую ревизию
только после загрузки и проверки необходимых файлов.

## Синхронизация

Экраны одной группы используют общий `timelineEpoch`. Фото, сцены и фразы меняются
по одной временной шкале. При отсутствии файла клиент показывает fallback в течение
его штатного интервала, чтобы не сдвигать остальную группу.

## Погода

Погоду запрашивает сервер через заменяемый provider adapter. Начальный источник —
Open-Meteo. Обновление выполняется раз в 15 минут. При ошибке сохраняется последний
успешный снимок; виджет умеет показывать возраст данных.

## Надёжность

- клиент продолжает последнюю готовую ревизию без сервера;
- текущая и предыдущая ревизии защищены от очистки кеша;
- файлы проверяются по SHA-256;
- watchdog перезапускает renderer;
- сервер публикует только полностью согласованную ревизию;
- база и медиа резервируются средствами Proxmox/PBS и логическим `pg_dump`.
