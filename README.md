# Digital Signage — ОГАУ ДО «СШ ВВЕ»

Локальная система цифровых экранов для любого современного браузера, включая
Raspberry Pi 5. Сервер работает в одном непривилегированном Debian 13 LXC на
Proxmox VE без Docker.

## Возможности 0.5.0

- библиотека фото, видео и сайтов;
- переименование, отключение и безопасное удаление контента;
- плейлисты с drag-and-drop порядком;
- расписание по датам, дням недели и времени;
- постоянные повторно копируемые ссылки экранов и несколько каналов;
- независимая очередь каждого дисплея: старт с начала при открытии страницы,
  затем повтор по кругу;
- ожидаемые расписания подключений: постоянно, через интервал или точные окна;
- потоковый режим по умолчанию и включаемое отдельно полное автономное хранение
  медиа с отображением готовности;
- автоматическое определение типа и подготовка видео в совместимый MP4/H.264/AAC;
- потоковая выдача видео по HTTP Range, `cover`, `contain`, `stretch`;
- управление звуком, переход к следующему/предыдущему элементу;
- встроенные часы, дата, погода и сменяющиеся фразы;
- создание неограниченного количества виджетов и объявлений с масштабом текста;
- живые сайты и серверные снимки сайтов;
- черновики и атомарная публикация;
- роли пользователь/модератор/администратор и управление учётными записями;
- встроенная русская вики по всем модулям и кнопкам;
- мониторинг экранов, нагрузки Debian LXC, служб и компактный журнал действий.

Для Pi, которые обычно показывают RTSP-камеру, достаточно передать постоянную
ссылку существующей программе переключения камеры/браузера. Она открывает ссылку
на нужное время и закрывает браузер. Каждый новый запуск начинает плейлист с
первого активного элемента. Установка Pi-Agent не требуется.

Расписание в панели описывает ожидаемое время связи для контроля дисплеев;
процесс браузера открывает и закрывает программа на устройстве. Например,
интервал 60 минут, длительность 10 минут, рабочее время 09:00–18:00 соответствует
окнам 09:00–09:10, 10:00–10:10 и далее до 17:00–17:10.

По умолчанию видео подгружается через HTTP Range по мере показа. Если включить
«Автономный показ», браузер последовательно сохранит полный плейлист, включая
видео. До отключения сети нужно дождаться статуса «Готов к работе без сети».
Живые сайты требуют сеть при любом режиме; для них доступны серверные снимки.

## Структура

```text
apps/server/       Django API, панель управления и web-player
apps/web/          статические ресурсы интерфейса и фирменная тема
deploy/lxc/        установка и systemd-конфигурация сервера
docs/              архитектура, эксплуатация и восстановление
```

## Целевая среда

- Proxmox VE 9.2.3;
- Debian 13 LXC, `unprivileged: 1`;
- PostgreSQL 17, Nginx, FFmpeg, Chromium;
- Python 3.13 и Django 5.2 LTS;
- любой Chromium/Chrome/Edge с Service Worker; Raspberry Pi OS 64-bit и Pi 5 поддерживаются.

Файл `.env` и любые секреты не добавляются в Git. Пример настроек находится
в `.env.example`. HTTPS использует сертификат существующего Microsoft CA;
установщик проверяет ключ, сертификат и цепочку, не заменяя имеющиеся TLS-файлы.
