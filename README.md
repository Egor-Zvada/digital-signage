# Digital Signage — ОГАУ ДО «СШ ВВЕ»

Локальная система цифровых экранов для любого современного браузера, включая
Raspberry Pi 5. Сервер работает в одном непривилегированном Debian 13 LXC на
Proxmox VE без Docker.

## Возможности v1

- библиотека фото, видео и сайтов;
- переименование, отключение и безопасное удаление контента;
- плейлисты с drag-and-drop порядком;
- расписание по датам, дням недели и времени;
- постоянные ссылки экранов и несколько каналов;
- циклическое воспроизведение и локальный кеш клиентов;
- автоматическое определение типа и подготовка видео в совместимый MP4/H.264/AAC;
- потоковая выдача видео по HTTP Range, `cover`, `contain`, `stretch`;
- управление звуком, переход к следующему/предыдущему элементу;
- синхронные группы экранов;
- встроенные часы, дата, погода и сменяющиеся фразы;
- создание неограниченного количества виджетов и объявлений с масштабом текста;
- живые сайты и серверные снимки сайтов;
- черновики и атомарная публикация;
- роли пользователь/модератор/администратор и управление учётными записями;
- встроенная русская вики по всем модулям и кнопкам;
- мониторинг экранов, нагрузки Debian LXC, служб и компактный журнал действий.

## Структура

```text
apps/server/       Django API, панель управления и web-player
apps/web/          статические ресурсы интерфейса и фирменная тема
deploy/lxc/        установка и systemd-конфигурация сервера
docs/              архитектура, эксплуатация и восстановление
```

## Целевая среда

- Proxmox VE 9.2.3;
- Debian 13 LXC, `unprivileged: 1`;
- PostgreSQL 17, Nginx, FFmpeg, Chromium;
- Python 3.13 и Django 5.2 LTS;
- любой Chromium/Chrome/Edge с Service Worker; Raspberry Pi OS 64-bit и Pi 5 поддерживаются.

Файл `.env` и любые секреты никогда не добавляются в Git. Пример настроек будет
находиться в `.env.example`.
